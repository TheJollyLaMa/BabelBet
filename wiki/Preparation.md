# Preparation, not wagering

See the [web guide](../prep/guide.html) for About, keyboard/reduced-motion bunny-hop
orientation, optional wallet, local profile privacy and opt-in DBuskRadio.

Available now: actual pinned DecentHead 2.0.0 with EIP-6963 account session and
shared IPFS host adapter; contextual left steward/right personal ankhs; language
bridge decoration; local profile import/export; optional music via the standalone
widget mount/destroy API. Wallets are optional and never authorization.

Unavailable: all official/unofficial Duolingo access, watchers, email, challenge
and wagering execution, public IPFS uploads/pins/rewards, assistant and financial
activation. No game, lifecycle, oracle, contract or deployment is introduced.

Historical source is retained as non-executable `history/*.source` from receiving
95a151d; supported runtime is a allowlisted static Node server. Old browser paths
return 410; operations return 405. Old Python/JS routes, migrations and consoles
fail closed with no flag to revive them.

The actual IPFS version-1 adapter exposes local-profile export/import as backup
controls. Public publishing is unconfigured rather than removed from the shared
facade. The app does not monkeypatch shared methods or inspect private header
shadows; explicit component deviations needed for host-only controls and ankh /
About events are documented in [DecentHead host bridge](DecentHead-Host-Bridge.md).

Participation is free. Offer accessible design, translations, offline tests,
privacy or permission research. Work must be accepted and reviewed by a steward;
register payout identity privately if a future approved budget exists. No private
roster is included, no payment is promised and no funds are sent.

Optional helper parity is documentation only: DecentBusking agent-service's
server-side boundary is a future lead, not an enabled integration. Do not copy
private handoff context/routing/deployment or BigNuten browser-key patterns.
